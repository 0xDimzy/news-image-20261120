A single front-page image of the world's news for **Friday 20 November 2026**:
43 stories across 6 regions, led by Cyclone Akvan's landfall in Odisha, the
Russian barrage on three Kyiv bridges, and the AI-driven rout across Asian
markets. Includes a stat strip, a UTC timeline of the day, REPORTED / CLAIM /
FORECAST tags, and a DATE CHECK box excluding Thursday's news.

## Files

- `entry.png` — the 1024×1024 front page (the submission image)
- `frontpage.html` — the source used to render `entry.png` (headless Chrome)
- `main.ts` — copies `entry.png` to `MAKEFUN_OUTPUT_DIR` (default `/output`)

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
