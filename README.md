A single front-page image of the world's news for **Friday 20 November 2026**:
30 verified stories across 7 regions — 3 illustrated leads (Cyclone Akvan's
landfall in Odisha, the ballistic barrage on Kyiv's three Dnipro bridges, and
COP31's deadlocked final day in Antalya), 10 drawn feature cards, a
numbered-pin world map, 17 one-line briefs, a six-number stat strip, and a
DATE CHECK box that names Thursday's news and excludes it. Every story
happened, or was first reported, on 20 November 2026; claims are attributed,
not stated as fact.

## Files

- `entry.png` — the 1024×1024 front page (the submission image)
- `frontpage.html` — the source used to render `entry.png` (headless Chrome)
- `main.ts` — copies `entry.png` to `MAKEFUN_OUTPUT_DIR` (default `/output`)

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
